# Constitución técnica

Principios innegociables para toda modificación.

1. **Simplicidad primero:** HTML, CSS y JavaScript puros sin framework salvo decisión documentada.
2. **Especificación viva:** cambios funcionales requieren spec, plan y validación.
3. **Separación:** datos, lógica y manipulación del DOM deben mantenerse diferenciados.
4. **Pruebas como puerta:** ningún cambio se considera listo con pruebas o validaciones fallidas.
5. **Datos protegidos:** nunca almacenar secretos o datos personales innecesarios.
6. **Comercio verificable:** mantener textos, precios y datos reales comprobados.
7. **Accesibilidad:** navegación por teclado, contraste, semántica y responsive son obligatorios.
8. **Idioma:** interfaz y documentación en español.
