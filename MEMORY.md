# Memoria del proyecto

- El sitio funciona como aplicación estática y debe mantenerse compatible con GitHub Pages.
- `js/data.js` concentra el catálogo y el número de WhatsApp.
- El público principal está en Panamá y la interfaz debe permanecer en español.
- Las cotizaciones se preparan en el navegador y se envían mediante WhatsApp.
- El sitio público no usa backend ni base de datos. `backend-python/` es código
  heredado excluido del artefacto de Pages; `seller-local/` es una herramienta
  manual sin autenticación ni persistencia, para uso local de ventas.
- No reemplazar afirmaciones comerciales ni datos de contacto sin confirmación del propietario.
- Evitar modificaciones masivas antes de establecer especificación y plan.
